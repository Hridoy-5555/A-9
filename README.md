# Doctor Appointment Manager (DocAppoint)

DocAppoint is a modern, full-stack healthcare management system designed to bridge the gap between patients and medical specialists. Users can browse highly-rated doctors, manage their health schedule, and book appointments through a secure and interactive interface.



## 🚀 Key Features

- **Dynamic Doctor Browsing:** Effortlessly explore a comprehensive list of medical specialists with real-time searching by name and sorting by consultation fees.
- **Secure Authentication:** Integrated robust authentication using Better Auth with social login (Google) and JWT-based session management to keep user data safe.
- **Interactive Appointment Management:** Logged-in users can book, review, update, and delete their medical appointments with instant UI updates (no page reloads required).
- **Personalized User Dashboard:** A dedicated private space for users to track their booking history and update their profile details, including name and photo.
- **Modern & Responsive UI:** Built with a "mobile-first" approach using Tailwind CSS and DaisyUI, featuring smooth animations (Framer Motion style) and a dark/light theme toggle.
- **SEO & Performance Optimized:** Implemented dynamic metadata for every route using `react-helmet-async` to ensure high visibility and a professional user experience.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, DaisyUI, React Router DOM
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Better Auth (Social & Email/Password)
- **Utilities:** React Hook Form, React Hot Toast, React Helmet Async, Lucide Icons
